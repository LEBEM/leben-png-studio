# LEBEN Studio — prototipo limpio v0.1.0

Este es un prototipo independiente creado para reconstruir primero la interfaz y el flujo de Personajes sin arrastrar la complejidad del proyecto anterior.

## Objetivo visual

- Ventana 1280×800.
- Cabecera compacta.
- LEBEN Studio + menús a la izquierda.
- Iluminación + Personajes junto a los controles de ventana.
- Selector de personajes en una ventana independiente.
- Tres tarjetas grandes por fila.
- Añadir personaje.
- Barra inferior para audio/estado.
- Paneles independientes para futuras herramientas.

## Siguiente etapa

1. Sustituir los avatares de texto por PNG reales.
2. Importación de personajes.
3. Guardado de perfiles.
4. Escenas y fondos.
5. Reacciones F1–F8.
6. Audio/micrófono real.
7. Editor 2D por piezas.
